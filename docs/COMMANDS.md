## Tips for Best Results

1. **Speak clearly** - Enunciate words properly
2. **Use full names** - "John Smith" instead of "John"
3. **Include context** - "Send SMS to mom: coming late" (not just "send message")
4. **Pause between commands** - Let Jarvis finish processing
5. **Check network** - Some commands need internet
6. **Update contacts** - Jarvis learns from your contacts

## Offline vs Online Commands

### ✅ Works Offline
- Open/close apps
- Control device settings
- Play local music
- Alarms & reminders
- Call/SMS (with numbers)
- Local contacts

### ⚠️ Needs Internet
- Weather
- News
- Web search
- Translation
- Navigation
- Cloud features

## Error Messages

| Error | Solution |
|-------|----------|
| "Didn't understand" | Speak clearly, use simple words |
| "No internet" | Enable WiFi/Mobile data |
| "Contact not found" | Add contact to phone |
| "Permission denied" | Grant app permissions |
| "Microphone error" | Check microphone, restart app |
